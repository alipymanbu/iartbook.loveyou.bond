安装前的准备

项目建议
系统版本安卓 5.2 及以上，低于该版本安装时会直接报不兼容（以安装包检测为准）
存储空间安装包 200.88M，加上安装后的占用，建议预留 1GB 以上余量
安装来源从网盘下载 APK 属于应用商店以外的安装方式，需临时允许一次「未知来源」
网络安装过程不需要联网；首次启动同意隐私政策后，教程、填色素材等内容需联网加载

四步装进手机

  1. 打开资源链接，转存并下载

    用夸克 App 或网页版登录自己的账号，把分享里的文件转存到自己网盘，再下载 APK 到手机存储。

  2. 点开 APK，允许这次安装

    在文件管理器或通知栏里点开下载好的 APK；首次安装会跳到「允许此来源应用安装」页面，打开开关后返回。

  3. 等待安装进度走完

    点「安装」后耐心等待——安装包接近 200M，在低端机上这一步会慢一些。

  4. 打开应用，同意隐私政策

    首次启动先弹隐私协议，同意后进入主界面；存储权限在第一次保存作品时才会请求，建议直接允许。

部分国产系统在安装后还会再弹一次「确认安装」，属于系统行为，正常确认即可。

第一次打开要同意什么

隐私政策

进主界面前先同意

首次启动先弹隐私协议，同意后才能进入「画册 / 创作 / 像素 / 我的」主界面。

存储权限

第一次保存时才弹

不是启动时就要：第一次往相册保存作品时才会请求。如果当时拒绝了，之后每次保存都会失败，需要到系统设置 → 应用 → 权限里手动打开。

照片 / 媒体权限

导入底稿时按需允许

想在「创作」板块导入相册里的图当底稿，会用到这个权限，按需允许即可。

拿到手的是不是这一版

搜「iArtbook」容易搜到好几款同名但完全不同的应用，装错名字后面对的就是另一套界面。

  • 包名com.tktn.ycfn
  • 版本2.2.7（更新内容为画板功能优化）
  • 安装包大小200.88M
  • MD5039BE953432445EF6D185890CFCA8080
  • 界面特征中文，主界面为「画册 / 创作 / 像素 / 我的」等板块

MD5 可用文件管理器或校验工具算一下安装包，32 位值对得上就说明文件没有下岔。

同名应用怎么区分

应用商店里另有一款英文专业绘画应用（版本号到 10.x，主打 Apple Pencil 与无限图层），安卓上还有一款轻量应用的包名是 risko.digitalpaint——界面都与本文介绍的中文安卓版完全不同。

核对包名是唯一可靠的办法；应用商店里能搜到更新的 2.3.x 版本，界面入口可能略有差异，操作类说明以设备上的实际界面为准。

装不上先看这三条

提示「禁止安装未知来源」

回到系统设置 → 应用 → 特殊权限 → 安装未知应用，给这次的安装来源（浏览器或文件管理器）打开「允许安装」，再重新点 APK。

提示空间不足

先清出 1GB 以上余量再装——200M 的安装包在解包阶段需要的临时空间比它自身还大。

提示解析失败或不兼容

多半是下载不完整（文件小于 200.88M）或系统版本低于 5.2：重新下载一次，或核对安卓版本。

装好之后从哪儿上手？

从首页的「界面入门」板块开始：认识画册、创作、像素几个入口，记住双指缩放、双指撤销这几个手势，再挑一种玩法（自由绘画 / 主题填色 / 逐帧动画）动手画第一张。
